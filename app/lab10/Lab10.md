# Lab 10 : Notifications


## Exercise 1 : Simple Local Notifications

Create an  application that reminds a user to drink water after a defined period.

The user should receive the notification popup if the app is in  background or killed.

When the notification pops up and  the user taps the notification, it should navigate to the Reminder screen with a message.


## Exercise 2 : Step counter

Create an application where user set a daily objectives of number of steps.

When the goal is reached the user should receive a local notification saying you reached your goal.

When the notification pops up and  the user taps the notification, it should navigate to a dedicated screen with details of number steps and any other interesting stats.
